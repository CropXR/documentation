# Command Line Tool

Data in the Resilience Hub is uploaded and downloaded with `rhub`, a command line tool. It uploads a folder of data and connects it to your metadata in the catalogue, and it downloads the datasets you have access to.

You use the tool in a terminal: "Terminal" on macOS and "PowerShell" on Windows. No programming experience is needed; the guides give every command to copy.

## In this section

1. **[Install the data tool](cli-install.md)**: install `rhub` and sign in. You do this once.
2. **[Upload a dataset](cli-upload.md)**: upload a folder of data to an assay in the catalogue.
3. **[Download a dataset](cli-download.md)**: download a dataset you found in the catalogue.
4. **[Common errors](cli-common-errors.md)**: what to do when a command gives an error.

!!! note "Before you upload"
    Your metadata has to be in the catalogue first, with the assay that the dataset belongs to. See [Before you upload](../seek/upload-prerequisites.md) and [SEEK Metadata Entry](../seek/index.md).
